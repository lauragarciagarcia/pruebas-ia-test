6. Características de Accesibilidad

El componente incluye características WCAG 2.1 compliant:

  • ✓ Asociación correcta entre label e input mediante atributos for e id
  • ✓ Soporte completo para navegación por teclado (Tab, Shift+Tab)
  • ✓ Atributos ARIA apropiados (aria-label, aria-describedby, aria-invalid, aria-required)
  • ✓ Mensajes de error con role="alert" y aria-live="polite"
  • ✓ Estados visuales claros (focus, hover, disabled, error)
  • ✓ Soporte para modo de alto contraste
  • ✓ Soporte para preferencias de movimiento reducido
  • ✓ Tamaño mínimo de fuente en móviles para prevenir zoom automático
